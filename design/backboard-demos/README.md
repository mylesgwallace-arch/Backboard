# Backboard style lab

Six visual worlds for the Backboard landing page, each built twice: once with the
**Taste** skill and once with the **Impeccable** skill. Twelve full landing pages
in total. Every page shows the same real model output, so only the style changes.

The 90s zine is the only world that carries the earlier retro brief, redone as
scrapbook and photocopy (tape, torn scraps, cut-out letters, typewriter captions)
instead of blacktop and spray paint.

## View it

From the repository root:

```sh
.venv/Scripts/python.exe -m http.server 4180 --directory design/backboard-demos
```

Open <http://localhost:4180/> for the gallery. Each page is also a standalone file
(`zine/taste.html`, `zine/impeccable.html`, and so on) that only needs `shared/`
and a network connection for Google Fonts.

Add `?slots` (or `#slots`) to any page URL to outline the image placeholders and
print each Higgsfield prompt.

## The six worlds

| World | Taste skill | Impeccable skill |
|---|---|---|
| Xerox zine | Composed collage on newsprint: ransom-note headline, taped photo slot, typed captions, pen marks on the real charts. | The zine is the object: stapled spreads on a photocopier lid. Feed two teams through the copier and it prints the sheet (scan bar, paper feed, typed numbers, a "tray empty" state). |
| Finals broadcast | Graphics package: lower-third pick, sticky keys-to-the-game panel, team-color data plates. | The page is the broadcast: a scorebug that picks the matchup, a lower-third that follows the segment, a pausable ticker, team-color replay wipes. |
| Hardwood court | Maple court, painted key and arcs that draw on scroll, a jump-ball circle split by win probability. | A shot chart: replay the game 1,000 times, one dot per replay, and every bar below is built from countable dots. |
| Trading card | Tilting foil cards, flip-to-read backs, a graded slab for the report card, a set sized by title odds. | Rip the pack. The pick card's finish (base under 55%, silver for a lean, gold at 70% and up) encodes confidence. |
| Arena scoreboard | Seven-segment numbers with drawn ghost segments, dot-matrix labels, a leaderboard for title odds. | A rigid LED mask: setting a team blinks the unset digits, PREDICT ignites the real numbers with a segment scramble. |
| Swiss poster | Team colors as flat fields where area equals odds, one proportional strip for the title race. | Full-bleed poster split at the win chance, a sentence-style picker, authored pictograms, a treemap of the title odds. |

## The data is real

`shared/demo-data.js` is generated by `tools/build_demo_data.py` from the
production engine's own tool layer. Nothing on the pages is mock data:

- win probability for all 870 ordered pairings (`elo_boosted_ensemble`), plus the
  group-ablation "why" breakdown and the projected score with its 80% range
- the holdout numbers (65.1% picked right on 13,332 games, log loss 0.6228) and the
  nine calibration bins
- the 2025-26 title odds beside what actually happened (the Knicks won at about 2%)
- the Curry-to-Spurs what-if, with its own "Confidence: Low" and backtest note

`shared/bb.js` is the small kit every page uses to read that data. The default
matchup on every page is the real 2025-26 Finals.

Regenerating needs `src/explain.py`, the calibration report and the what-if tool,
which live on the `claude/model-transparency` branch. The generated file itself is
static and needs none of them.

## How each page was built

Both skills were followed for the pages they own.

**Taste pages.** Each opens with a one-line design read and dial values (variance,
motion, density), then follows the skill's structure rules: hero that fits the
viewport with at most four text elements, one accent color, one corner-radius rule,
no eyebrows or section numbers, no em dashes, no hand-drawn icons, no fake product
screenshots, motion that is honored under `prefers-reduced-motion`.

| World | Design read | Dials |
|---|---|---|
| Zine | consumer sports landing for casual fans, photocopied-zine scrapbook language, native CSS collage | 9 / 5 / 4 |
| Broadcast | Finals-broadcast graphics language, native CSS and scroll motion | 8 / 7 / 4 |
| Hardwood | top-down maple court language, native CSS and SVG line drawing | 8 / 6 / 4 |
| Trading card | collector's-table language, foil and pointer tilt via CSS variables | 8 / 7 / 4 |
| Scoreboard | arena LED language, seven-segment SVG and dot-matrix type | 7 / 6 / 4 |
| Swiss poster | modernist poster language, native CSS grid, one grotesk | 6 / 4 / 5 |

**Impeccable pages.** Each has a direction contract (thesis, own-world, story, first
viewport, form) kept in `.impeccable/surfaces/` and never shipped in the HTML. The
craft floor was applied: no kickers or section numbers, no gradient text, themed
selection, focus, scrollbar and caret, real hover, disabled, loading, empty and
error states. The one direction roll landed on the trading card, and the
seven-segment challenger was fused into the scoreboard.

Not run for these exploratory pages: Impeccable's finish-review subagent and its
DESIGN.md documenter (six competing worlds cannot share one DESIGN.md until one is
chosen). The detector was run once; the findings that remain are intentional
materials (torn-tape edges, graph paper, plank seams, an inset recessed-window
shadow) or the detector misreading `clamp()` values.

## Verification

- Every page loaded with no console errors and was inspected at 1440 and 390 wide.
- Horizontal overflow was measured at 390 on all twelve pages.
- The batch predictions were cross-checked against the CLI: Boston over the Lakers
  is 0.6930 either way.
- Animation timing (the copier, pack rip, replay wipe, dot landing) was checked by
  driving the states directly, not by watching a live frame loop.
